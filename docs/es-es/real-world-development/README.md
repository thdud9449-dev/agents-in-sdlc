Explora GitHub Copilot en todo el ciclo de vida del desarrollo de software con escenarios realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar comportamientos, revisar pull requests y gestionar el trabajo con agentes.

## Escenario

Eres un desarrollador nuevo en Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. El backlog de tu equipo ya está documentado como incidencias de GitHub, listas para que las recojas. Incluye trabajo de funcionalidad como el filtrado y la paginación junto con mejoras de calidad como la accesibilidad y las normas de codificación.

## Elige tu entorno

GitHub Copilot te acompaña donde trabajes. Elige el entorno que mejor se adapte a la forma en que quieres crear. Cada taller empieza con su propia configuración y usa el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes en tu terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y comandos con barra prácticos.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agente en paralelo, cambia de modo de sesión, colabora en lienzos y gestiona incidencias y pull requests de GitHub en la aplicación de escritorio.

### [Agente de GitHub Copilot en la nube][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa el progreso y revisa las pull requests que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo de agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.

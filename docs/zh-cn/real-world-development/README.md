使用 GitHub Copilot 来完成软件开发生命周期中的真实场景练习，包括完整应用和共享待办事项。你将迭代地规划变更、创建代码、测试行为、审查拉取请求，并利用智能体来管理工作。

## 场景

你是一名 Tailspin Toys 的新开发者，这是一家虚构的公司，专门为具有开发者主题的桌游提供众筹。团队的待办事项已经整理成 GitHub issue，供你挑选。它包含功能开发，例如筛选和分页，以及质量改进，例如无障碍和编码标准。

## 选择你的环境

GitHub Copilot 能在你工作的任何地方为你提供支持。选择与你希望构建方式匹配的环境。每个工作坊都从自己的设置开始，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。与 Plan 和 Autopilot 模式、说明、技能、自定义智能体、Playwright MCP 以及实用的斜杠命令一起工作。

### [GitHub Copilot app][app]

运行并行的智能体会话，切换会话模式，在桌面应用中协作使用画布，并管理 GitHub issue 和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub issue 分配给异步智能体，指导它的工作，监控进度，并审查它打开的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。直接在编辑器中使用 Copilot Chat 代理模式、MCP 服务器和自定义智能体。
